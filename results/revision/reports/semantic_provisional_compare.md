### 3b. 요약 (기술 집계, 해석·검정 아님)

- 키워드 기준 모바일 FP 페이지는 RAG 끔이 켬보다 3회 평균 +19.3 많다.
- 의미 채점 pass1 기준으로는 그 차이가 (i) +1.7, (ii) +1.0 페이지다.
  키워드에만 모바일 양성인 이슈(6 run 합계 303건, 이슈 단위)는 의미 채점에서 버튼 224건, None 79건을 받았다(3a).
  RAG 끔에서 늘어난 키워드만 이슈는 주로 'viewport' 언급(None)이다(3a 의 run 별 열).
- 모바일 TP 는 두 채점기, 두 조건 모두 56/56 이다.
- 잘린 이슈 중 키워드 모바일 양성은 없으므로(잘림 보고서 d1) 모바일 비교는 잘림 처리 방식의 영향을
  (ii) 의 페이지 집합 변화로만 받는다.
