작성 2026-11-18. API 호출 없음. 코드: `experiments/revision/e7_final.py`.
전체 표: `results/revision/e7_final/e7_final_tables.md` (같은 폴더에 CSV).

- **사전 지정 10절 5항 준수:** 사람 평가(E5, E5b) 결과를 본 뒤 채점 모델, 프롬프트(JUDGE_PROMPT v1), 설정,
  키워드 사전, string_match 규칙을 바꾸지 않았다. 이 분석은 이미 있는 재채점 병합 통합표를 읽기만 했다.
- **채점기를 바꾼 시점:** 주 채점기를 키워드에서 의미 채점(재채점 병합)으로 바꾼 것은 사람 평가 E5b 에서 키워드의
  약점(예: 모바일 정밀도 0.704, 중복 ID 재현율 0.667, 표준 용어 오탐 7건)이 확인된 뒤의 결정이다.
  비교 구조(주 비교 R1 − A1-1, 반복 R2 − A1-2, R3b − A1-3, 다수결)와 지표, 라벨 층, 부트스트랩은 사전 지정
  (analysis_plan.md 5절, 10절)과 기존 E7 그대로다. 키워드 결과를 같은 형식의 보조 표로 나란히 둔다.
- 기존 E7(`results/revision/e7/`)은 바꾸지 않았다. 이 스크립트가 다시 계산한 키워드·string_match 결과는 기존 E7 과
  셀 예측 0개 차이, 셀 지표·짝 비교·변동 표의 겹치는 행이 모두 같은 값이다(같은 시드).
- 채점기와 무관한 기존 표(이슈 수 분포, 카테고리 구성, total_checked_count, 점수 AUC, 페이지 단위 표)는 다시 계산하지 않았다.
- 채점기: 의미(병합) = 주, 의미(원) = 원 pass1 규칙(잘림 = 음성) 민감도, 키워드 = 보조, string_match = 용어만.
- 구간: 템플릿 짝 군집 부트스트랩(B 10,000, 시드 20261111, 백분위 95%). * = 차이 구간이 0 을 포함하지 않음.
  검정(McNemar)은 이번에 다시 하지 않았다.

## 6. 해석 주의사항

- **템플릿 10개.** 군집 부트스트랩의 재표집 단위가 10개뿐이라 구간이 좁게 나올 수 있고(계획서 5절 한계), 구간 끝이
  0.000 근처인 결과(예: 다수결 effective 의미 MCC -0.017 [-0.040, -0.000]*)는 반올림에 따라 판정이 바뀔 수 있다.
- **단위 독립성 가정.** 구간은 템플릿을 독립 단위로 보고, 같은 템플릿 안의 페이지·셀은 통째로 움직인다. 같은 페이지의
  5개 유형 셀, 같은 LLM 응답에서 나온 여러 이슈는 서로 독립이 아니며 이 상관은 템플릿 수준까지만 반영된다.
  E1 세 run 과 A1 세 run 을 쌍으로 묶은 것도 실행 순서에 따른 임의 짝이다.
- **채점기에 따라 결론이 달라진다.** 키워드 기준으로는 모든 비교·라벨에서 RAG 켬의 MCC 점추정이 0.06~0.23 높았다
  (R2 − A1-2 의 effective, 근거+버튼은 구간이 0 을 포함). 의미 채점
  기준으로는 MCC 차이가 0 근처(-0.020 ~ +0.010)이고, 정밀도·특이도는 약간 높고 재현율은 약간 낮다. 키워드 기준의
  RAG 효과는 주로 키워드의 오탐(RAG 끔 조건에서 더 많음)이 줄어든 데서 나온 것으로 보이며, 의미 채점 기준에서는
  재현되지 않는다. 논문에서 RAG 효과를 말할 때 채점기를 함께 밝혀야 한다.
- **사람 평가 범위.** 의미 채점의 사람 대비 검증(E5b)은 E1-R1 이슈(A·B 범위 204건, 층화 표본)와 추가 세트(107건)에만
  있다. RAG 끔(A1) run 의 이슈는 사람이 보지 않았다. 표준 용어 유형은 본 평가 범위에 사람 양성이 없어 의미 채점의
  용어 재현율을 사람 기준으로 확인할 수 없다. 평가자가 저자이고 불일치는 합의 회의로 정했다(`reports/e5b_report.md`).
- 라벨은 주입 기록(nominal)과 결정적 검사(effective)이며 사람 판정이 아니다. 근거(대비) 층은 명도 대비 200셀뿐이다.
- `paper_numbers.py` 와 논문 숫자표는 이번에 갱신하지 않았다.
