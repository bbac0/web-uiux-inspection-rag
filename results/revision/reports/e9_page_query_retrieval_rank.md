# E9 페이지별 질의: 관련 조항 6청크의 전체 순위와 Recall@k

작성: `experiments/revision/e9_page_query_rank.py` (임베딩), `e9_page_query_rank_report.py` (이 보고서).
질의 = e9-main-page-r1, r2 의 rag.query 중 서로 다른 것 10개 (질의 생성 규칙은 그대로).
질의마다 gemini-embedding-001 embed_query 1회, 전체 1020청크 L2 순위(프로덕션 검색과 같은 연산).
검증: 각 질의 순위의 1~4위가 run 에 기록된 가져온 청크와 같음 10/10.
호출: 성공 10회 + 첫 시도 1회(스크립트 비교 코드 오류로 첫 질의 뒤 멈춤,
폴더 `results/revision/e9/page_query_embedding_attempt1_failed` 에 보존).
비용 추정 상한(글자 수 = 토큰, $0.15/1M) $0.000018 (상한 $0.05).
Recall@k = 6청크 중 k위 안에 든 비율. 통계 검정 없음.
