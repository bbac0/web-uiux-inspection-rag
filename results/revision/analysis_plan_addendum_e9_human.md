# 분석 계획 부록: E9 사람 평가 (정규식 정확도 검증)

작성일: 2026-11-18. 표본을 뽑기 전, 평가자 입력과 결과를 보기 전에 커밋한다. API 호출 없음.
동결 문서(`exp-freeze-e9-v4` 의 E9 분석 계획, `exp-freeze-v5`, `exp-freeze-v6-semretry`)는 고치지 않는다.

## 1. 목적

E9 주 지표인 결정적 정규식(`scoring/e9_rules.py`, 동결)이 이슈 단위로 결함 유형을 옳게 잡는지 사람 판정과 비교한다.
판정 항목: 배너 문구 지적(E9-1 대응), 규격값 지적(E9-2 대응), 로그인 주소 지적(E9-3 대응). E9-4(보조 규칙)는 다루지 않는다.

## 2. 모집단

- run: `results/revision/runs_e9/e9-main-related-r1`, `results/revision/runs_e9/e9-main-norag-r1`.
- 이슈: 각 run 의 대상 페이지 이슈. 정의는 `experiments/revision/e9_regex_table.target_issues` 그대로
  (description 앞 `[URL]` 부분에 `/{page_id}.html` 이 있는 이슈, 페이지 상태가 ok 인 경우만).
- 페이지 정보: `testbed_e9/dataset_metadata_e9.json`.

## 3. 층

- 페이지 층(4개): E9-1 결함 페이지(defect_id = E9-1, 1a·1b 포함), E9-2 결함 페이지, E9-3 결함 페이지, 대조군(subtype = control).
  E9-4 결함 페이지는 넣지 않는다.
- 이슈 층(2개): 정규식 주 지표(`e9_rules.match_issue`, E9-1 결함 페이지는 그 페이지에 주입된 문구를 함께 넘김)가
  - 결함 페이지: 그 페이지의 결함 유형(E9-1, E9-2, E9-3)으로 그 이슈를 잡았으면 '걸림', 아니면 '안 걸림'.
  - 대조군: E9-1, E9-2, E9-3 중 하나라도 잡았으면 '걸림', 아니면 '안 걸림'.
  - 결함 페이지의 이슈가 그 페이지 유형이 아닌 다른 유형으로 잡힌 경우는 '안 걸림' 층에 두고, 다른 유형 판정은 key/ 에 기록한다.

## 4. 표본

- 페이지: 페이지 층마다 page_id 오름차순 목록에서 `random.Random(20261201)` 한 개 인스턴스로
  E9-1, E9-2, E9-3, 대조군 순서로 `sample(목록, min(15, 건수))` 를 한다(E9-2, E9-3 은 15페이지뿐이라 전부,
  E9-1 은 16페이지 중 15, 대조군은 30페이지 중 15).
- **같은 페이지 표본을 두 조건(related-r1, norag-r1)에 함께 쓴다**(조건 간 페이지 구성 차이를 없애기 위함).
- 이슈: 표본 페이지마다, 조건 순서(related-r1, norag-r1), page_id 오름차순으로 돌며
  - '걸림' 이슈는 전부 넣는다.
  - '안 걸림' 이슈는 issue 순번 오름차순 목록에서 `random.Random(20261202)` 한 개 인스턴스로 `sample(목록, min(2, 건수))`.
- 중복 문장은 합치지 않는다(조건과 페이지가 다르면 다른 이슈로 본다). 같은 문장의 반복 횟수는 key/ 에 적는다.
- 총 이슈 수가 150건을 넘으면 시트를 만들기 전에 연구자에게 알리고 지시를 받는다.

## 5. 시트 (연구자 승인 후 생성)

- 평가자 A, B 가 같은 이슈 전체를 독립 판정한다(`human_eval/e9_eval/rater_A_e9/`, `rater_B_e9/`).
- 열: issue_id, 스크린샷 경로, 이슈 설명, 제안, 배너 문구 지적(예/아니오), 규격값 지적(예/아니오), 로그인 주소 지적(예/아니오), 비고.
- 조건명, run 이름, 페이지 결함 유형, 주입 정보, 정규식 결과, 층은 시트와 뷰어에 넣지 않고 `e9_eval/key/` 에만 둔다.
  issue_id 와 스크린샷 파일명은 무작위 토큰, 행 순서는 평가자별로 다른 시드로 섞는다.

## 6. 분석

- 이 시트는 채점 결과(정규식)로 층을 나눠 뽑은 표본이므로 **disagreement_focus** 성격이다.
- 정규식 정확도는 **층별(정규식 걸림 / 안 걸림 × 페이지 유형, 조건별)로만** 보고한다. 층을 합친 전체 정확도(정밀도·재현율)는
  내지 않는다. '안 걸림' 층은 페이지당 최대 2건의 무작위 표본이라 모집단 비율과 다르다.
- 평가자 간 일치도는 합의 전 원 답으로 계산한다(열별 일치율, Cohen's kappa, PABAK, AC1).
- 사람 기준은 두 평가자 일치 + 불일치 합의 결과로 하고, 합의 절차는 본 평가와 같다.
- 정규식 비교: 사람 기준 대 정규식 주 지표(주), 보조 규칙(`scoring/e9_rules_aux.py`)은 보조 분석. 기술 통계만, 검정 없음.
- 사람 평가 결과를 본 뒤 정규식 규칙(동결)을 바꾸지 않는다.
