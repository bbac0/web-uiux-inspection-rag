## a. 대조군에서 정규식에 걸린 이슈 (파일럿 5조건 전체)

파일럿 대조군은 `e9p_002`(본문 portal_main)와 `e9p_008`(본문 contact_page) 두 페이지다.
주 = 주 지표 규칙, 보조 = 6개 변형 문구 전체 적용 규칙. 이슈 번호는 그 페이지 대상 이슈 안의 순번(0부터)이다.

| 조건 | 페이지 | 이슈 | 주 | 보조 | 걸린 규칙과 키워드 |
|---|---|---|---|---|---|
| RAG 끔 | e9p_002 | 1 | E9-1 | E9-1 | E9-1 주제어 절: '배너' + '텍스트' |
| RAG 끔 | e9p_002 | 3 | E9-1, E9-2 | E9-1, E9-2 | E9-1: '배너' + '문구' / E9-2: '배너' + '#D8D8D8' |
| 고정 질의 | e9p_002 | 0 | E9-1 | E9-1 | E9-1 주제어 절: '배너' + '내용' |
| 관련 조항 제공 | e9p_008 | 0 | E9-2 | E9-2 | E9-2: '공식 배너' + 'px' |

페이지별 질의와 fixed-long 에서는 대조군 이슈가 정규식에 걸리지 않았다.

이슈 설명 앞 150자 (URL 접두어 제거, description + suggestion):

- **RAG 끔 e9p_002 #1:** 메인 콘텐츠 영역의 '배너' 텍스트가 플레이스홀더로 보입니다. 실제 콘텐츠가 아닌 임시 텍스트가
  노출되고 있습니다. 플레이스홀더 '배너' 텍스트를 실제 사용자에게 유용한 정보나 홍보 콘텐츠로 교체하세요.
- **RAG 끔 e9p_002 #3:** 상단 배너의 '.flag' 요소가 회색 배경(`background:#D8D8D8`)으로만 표시되어 있어 '대한민국 공식 전자정부
  누리집'이라는 문구와 어울리는 실제 국기 이미지가 아닙니다. `.flag` 요소에 대한민국 국기 이미지(SVG 또는 PNG)를 적용하여 시각
- **고정 질의 e9p_002 #0:** 메인 콘텐츠 영역에 실제 배너 내용 대신 '배너'라는 플레이스홀더 텍스트가 표시됩니다. 메인 배너는
  서비스의 주요 정보나 홍보 내용을 담아야 하므로, 플레이스홀더 텍스트를 실제 콘텐츠(이미지, 텍스트, 링크 등)로 교체하여 사용자에게 유의미한 정보를 제공해야 합니다.
- **관련 조항 제공 e9p_008 #0:** 공식 배너에 국기 아이콘 대신 회색 배경의 플레이스홀더가 사용되었습니다. 이는 '운영기관 식별자의
  로고 영역에 상위 기관의 로고를 제공하고 있다'는 가이드라인에 부합하지 않습니다. 공식 배너의 국기 아이콘 영역에 대한민국 국기 아이콘(24px X 16px)을 제공해야

**조항 문장을 그대로 가져와 결함이 아닌 것을 지적한 이슈 2건(관련 조항 제공, e9p_008)의 집계 여부:**

| 이슈 | 내용 | 주 지표 | 보조 분석 |
|---|---|---|---|
| e9p_008 #0 | 공식 배너 국기 자리 + '상위 기관 로고' 조항 문장 | **위양성으로 셈 (E9-2)** | **위양성으로 셈 (E9-2)** |
| e9p_008 #1 | 푸터 + '상위 기관 로고' 조항 문장 | 세지 않음 (어느 규칙에도 안 걸림) | 세지 않음 |

#0 이 E9-2 에 걸린 것은 조항 문장 때문이 아니라 같은 이슈에 들어 있는 '공식 배너'와 '24px'(국기 크기) 때문이다.

## c. 최소 수정안 (diff 미리보기, 적용하지 않음)

대상 파일은 `experiments/revision/e9_generate.py` 하나다. 그 안에서도 기준 골격(BASE_RULES, `build_page`)과
본문 재사용 규칙(`load_templates`)만 바꾼다. `render()` 의 주입 분기, E9_1A·E9_1B·E9_2_* 변형 목록, E9_4_MEDIA 는 그대로 둔다.

```diff
@@ BASE_RULES
-    (".gov-banner .flag", {"width": "24px", "height": "16px", "background": "#D8D8D8"}),
+    (".gov-banner .flag", {"width": "24px", "height": "16px"}),

@@ load_templates()  (본문 재사용 규칙: 로그인 링크 제거에 한 줄 추가)
         main = main.replace('<a href="/login">로그인</a>', "")
+        main = main.replace('<div id="main-banner">배너</div>', '<div id="main-notice">주요 소식</div>')

@@ build_page()
-            f"<div class=\"gov-banner\" id=\"gov-banner\"><span class=\"flag\" aria-hidden=\"true\"></span>"
+            f"<div class=\"gov-banner\" id=\"gov-banner\"><img class=\"flag\" src=\"/flag.svg\" alt=\"대한민국 국기\" width=\"24\" height=\"16\">"
 ...
-            "<p class=\"ft-copy\">© 정부 서비스. All rights reserved.</p></footer></body></html>")
+            "<p class=\"ft-copy\">© 2026 정부 서비스. All rights reserved.</p></footer></body></html>")

@@ main()  (목적지 페이지와 함께 국기 그림 파일 생성)
+    write testbed_e9/flag.svg  (24×16 태극기 SVG: 흰 바탕, 빨강·파랑 태극, 네 괘)
```

- (c1) 국기 자리와 (c2) portal_main 본문 문구가 위양성을 없애는 핵심 수정이다.
- (c3) 저작권 연도는 선택 사항이다. 위양성과는 관계가 없고 이슈 자리를 줄이려는 수정이다.
- 파일럿 생성기(`e9_generate_pilot.py`)는 `render()` 를 그대로 쓰므로 함께 바뀐다(파일럿 폴더에도 `flag.svg` 를 만든다).

**확인 방법 (적용 직후, API 없음)**

1. 결정적 검증이 모두 통과해야 한다.
   - `e9_verify.py`(본 실험 91), `e9_verify.py --testbed pilot`(8) 모두 통과.
   - 국기 크기 검사(`banner_flag_size`, 24×16)는 `img` 의 width/height 로 그대로 성립한다.
2. 주입 결함의 정의와 위치가 바뀌지 않아야 한다. 수정 전후 `dataset_metadata_e9.json` 을 페이지별로 비교한다.
   - **같아야 하는 필드:** page_id, subtype, body_template, defect_id, intensity, variant,
     injected_string, expected_failing_checks.
   - **바뀌어도 되는 필드:** bytes, base_css.
   - `ground_truth_e9.csv` 에서 바뀌어도 되는 것은 주입 문자열 오프셋(국기 태그 길이 차이만큼 이동), 렌더링 글자 수, 요소 사각형뿐이다.
   - in_first_5000, in_viewport, structurally_undetectable, verification_pass 가 하나라도 바뀌면 알린다.
3. 새 문구가 다른 규칙의 키워드를 새로 건드리지 않아야 한다.
   - 대상 문자열: '주요 소식', 'main-notice', '대한민국 국기', '/flag.svg', '2026'.
   - 이 문자열들에 `scoring/e9_rules.py` 의 모든 패턴
     (E9_1_TOPIC/ASPECT, E9_2_REGION/PROP, E9_3_A/B, E9_4_A/B/C)과
     '로그인', '헤더', '푸터', '배너', '회원가입' 을 적용해 일치가 0건임을 확인하는 단위 테스트를 둔다.
   - 미리 본 결과: 'px'·'#hex' 같은 속성어도 새 문자열에는 없다(국기 크기는 HTML 속성 width="24" 로 쓰고 'px' 를 쓰지 않음).

   `testbed_e9/` 와 `testbed_e9_pilot/` 를 재생성한다.
2. 변경 파일 해시 diff 를 만든다.
   - **예상 범위:** 91 + 8 페이지 HTML, 두 메타데이터, 두 ground truth, 두 검증 요약, `flag.svg` 2개(새 파일), 해시 목록 파일.
   - 그 밖의 파일(조건 입력, 정규식 규칙, 판정 프롬프트, 러너, 분석 계획 본문)이 바뀌면 멈추고 알린다.
3. `exp-freeze-e9-v3` 로 다시 태그한다. `freeze_manifest_e9.py` 자체를 동결 목록에 넣고, 이 수정안 문서도 넣는다.
4. README 계획 이탈 기록에 수정 내용(c1~c3), 이유(파일럿 대조군 위양성 4건의 입력 원인), v3 태그를 적는다.
5. 재파일럿을 1회 한다(8페이지 × 5조건, 약 $0.4, 의미 채점 없음). 결과는 분석에서 제외한다.
6. **수정과 재파일럿은 각각 한 번으로 끝낸다.** 재파일럿 뒤에도 대조군 위양성이 남으면 **추가 수정 없이 그대로 보고**하고,
   본 실험은 v3 입력으로 진행한다. 정규식 규칙은 어떤 경우에도 파일럿 결과를 보고 바꾸지 않는다.

## e. 수정하지 않을 때의 영향

국기 자리와 portal_main 본문의 '배너'는 모든 조건에 똑같이 들어가는 입력이다. 그래서 수정하지 않아도 조건 간 비교는 유효하다.
다섯 조건 모두 같은 페이지·같은 골격을 받으므로, 이 요소가 만드는 위양성은 조건과 무관한 바닥값으로 더해진다.
영향을 받는 것은 **절대 수준**이다. E9-1·E9-2 의 대조군 위양성률이 올라가 특이도와 정밀도가 낮게 나온다.
다만 이 위양성이 생길 확률이 조건에 따라 다를 수는 있다. 파일럿에서도 RAG 끔·고정 질의는 '배너 텍스트'를, 관련 조항 제공은
'국기 아이콘'을 지적했다. 그러면 조건 간 차이에도 작은 잡음이 섞일 수 있다.
수정하지 않기로 하면 대조군 위양성 이슈를 원인(골격·본문 자리 표시)별로 따로 세어 표에 병기하는 것을 제안한다.
